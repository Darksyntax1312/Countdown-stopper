⏱️ ClockWatch - Timer Application

A fully functional countdown timer web application with start, stop, resume, and reset capabilities.

✨ Features

    Start Timer – Begin countdown from user-defined time

    Stop Timer – Pause the countdown at any moment

    Resume Timer – Continue countdown from where it stopped

    Reset Timer – Instantly reset to 0

    Custom Time Input – Set any timer duration in seconds

    Visual Feedback – Large, prominent timer display with color coding

    Alert Notification – Pop-up notification when timer reaches zero

    Console Logging – Real-time countdown tracking in developer console

🧮 How It Works

The timer uses JavaScript's setInterval function to decrement the counter every second:

    User inputs a time value in seconds

    Clicking Start begins the countdown

    Each second, the display updates with the remaining time

    When counter reaches 0, the interval clears and an alert triggers

    Stop pauses the interval without resetting

    Resume continues from the paused value

    Reset clears everything and sets display to 0
